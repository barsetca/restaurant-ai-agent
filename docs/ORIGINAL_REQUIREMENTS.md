## Дополнительные подтвержденные требования (после ТЗ v1.0)
- Google Sheets содержит `FAQ`, `Menu`, `Settings`. Администратор редактирует эти вкладки; синхронизация запускается через admin UI без перезапуска.
- PostgreSQL — runtime source of truth для меню, цен и настроек. Валидация и атомарное обновление при синхронизации; при ошибке остаются предыдущие корректные данные.
- Стоимость доставки изменяемая, не фиксируется в коде. `orders.delivery_fee_minor` сохраняет значение на момент подтверждения.
- При изменении итоговой суммы до подтверждения показывать новый итог и требовать повторное подтверждение.
- Telegram long polling; один демонстрационный ресторан; русский интерфейс; EUR; Google Calendar через `calendar_jobs` и безопасный retry.
- `history/` игнорируется Git; после каждого задания русский Markdown-отчет, а после изменений — очищенный ZIP-снимок.

## Обязательный стек
Python 3.12, FastAPI, python-telegram-bot, OpenAI, LangChain, LangGraph, Qdrant, Python MCP SDK (stdio), PostgreSQL, SQLAlchemy, Alembic, Google Sheets API/gspread, Google Calendar API, Docker Compose, pytest. `uv` рекомендуется для зависимостей.

## Вне scope
Реальные платежи, курьеры, касса, мультиресторанность, голос, Kubernetes, GitHub Actions, n8n, AWS Bedrock, Anthropic, второй LLM-провайдер. Langfuse — только необязательное улучшение после MVP.

## Общие критерии сдачи
Минимум 15 evaluation-сценариев; README и запуск `docker compose up --build` после конфигурации; отдельные миграции и FAQ-индексация; тестовый календарь; публичный GitHub; ТЗ DOCX; скриншоты и скринкаст. Использовать только синтетические данные.
